# D'VINE

D'VINE is an 18-hour UI/UX design hackathon centered on turning ideas into working prototypes. Jointly organized by **IEEE SB CEC** and **IEDC Bootcamp CEC**, the event brings together 60 participants competing individually or in teams of two for an exciting prize pool.

> From vision to creation.

## Tech Stack

- [Next.js](https://nextjs.org/) with the App Router
- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- ESLint

## Theme

The website uses the **Neon Dusk** color palette:

| Token | Color |
| --- | --- |
| Background | `#020024` |
| Surface | `#081E3D` |
| Primary | `#0066CC` |
| Accent | `#00D4FF` |
| Foreground | `#E6F4FF` |

The primary typeface is **Owners**, loaded locally from `public/assets/owners.ttf`.
